# 节点列表质量缓存

本切片复用已合并的 PR15 只读批量缓存契约与 PR14 详情面板。进入节点页不自动读取质量缓存，也不发起检测。点击「读取本页质量缓存」后只处理当前页，用户可随时「取消读取」。

- 最多 50 个唯一节点一批，串行请求，批次之间等待 600ms；没有自动重试或后台刷新。5000 行页面最多 100 批，显示已处理数量。
- 进度表示已处理的缓存读取项，包含无缓存和逐项错误，不表示成功检测数量。
- 每次请求含响应读取最多 20 秒。取消会中止当前请求、停止后续批次，保留已完成项；超时、429 和一般错误停止后续批次并提示，401/403/503 清除本次全部已读结果。
- 换页、筛选（包括尚在防抖的文字）、排序、页大小、节点集合、出口 IP 或出口更新时间改变时，旧请求被取消、旧徽标失效；离开后返回同一范围也不会恢复旧读取状态。卸载页面会取消请求。
- 徽标分别表达有缓存、部分来源失败、全部来源未成功、无缓存、出口变化、结果太大及读取失败。不存在数据时保持未知，不生成风险评分，不推断健康或安全。
- 一项缓存任何来源达到有效期即隐藏徽标事实并显示已过期；定时器只更新显示，不刷新网络。列表只保留状态、IP 类型、来源数量、最早到期时间，不长期保留完整来源载荷。
- 点击徽标打开现有详情面板，通过单节点缓存 GET 和来源目录 GET 查看原始结果；大结果也使用这个显式入口。不会对每行自动补发 GET。
- 徽标可通过键盘进入；详情抽屉有可访问名称、初始焦点、Tab 循环、Escape 关闭及焦点恢复；进度有名称，结果通过状态区域播报。

## 可复现验证

在 `webui` 中执行 `npm ci`、`npm test`、`npm run test:browser`、`npm run build`。浏览器测试需要 Node 22+ 和本机 Chrome/Chromium，可用 `CHROME_PATH` 指定。使用单独临时浏览器配置及随机回环端口；全部 API 被 fixture 接管，不允许回退到真实 fetch。

测试覆盖分批与间隔、逐项/逐来源失败、禁用和权限错误、429 不重试、真实 20 秒超时、当前请求和批次间隔取消、页面卸载、换页/筛选/出口版本、A→B→A 防旧状态复活、到期无请求、详情 GET、键盘/对话框与中英文移动布局。截图和结果写入临时目录，也可通过 `BROWSER_ARTIFACTS_DIR` 指定本次运行产物目录。

本分支 CI 在 Ubuntu 22.04 与 Windows 2022 顺序运行上述 WebUI 检查和 Go 全量 test/race/build/vet。PR 描述记录实际运行和最终 tree；成功只覆盖被测组合，不能替代未来重定向 base 后的新检查，也不代表真实节点检测或上线。

## 后续边界

本列表缓存切片不包含 by-IP 页面、手动检测控件、批量检测任务、后台周期检测、来源配额或凭据来源。后续[显式节点定期检测](ip-quality-periodic.zh-CN.md)仍默认关闭，不由缓存 UI 隐式启用；风险级别仍为 unknown。评分依据、P3 过滤和 P4 DNS/capability 研究各自留在[公开路线图](ip-quality-roadmap.zh-CN.md)。没有修改生产服务、创建发行、部署、读取/创建密钥或执行真实节点探测。
