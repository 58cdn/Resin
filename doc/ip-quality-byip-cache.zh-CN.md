# 按 IP 查看质量缓存

此切片基于已合并的 master `def0caddb9bc6db90b88504a3e4f7274adf31595`，独立于尚待合并批准的列表 UI PR17。它交付独立草稿，不包含单次检测按钮、后端改动或真实节点验收；最终 HEAD、独立审查及自身 CI 以本 PR 描述为准。

## 入口与请求

在「资源」页点击「按 IP 查看质量缓存」，进入 `/resources/ip-quality`。输入 IPv4 或 IPv6 并显式点击「读取缓存」或按 Enter：

1. 规范化 IP 字面量，发送 `GET /api/v1/ip-checks/{ip}`。
2. 结果有效时读取 `GET /api/v1/ip-checks/sources`，只展示 by-IP 来源状态。

两次 GET 使用 `cache: no-store`，没有 lookup/check POST、插件启用或外部目标请求。初次进入、输入修改、聚焦、重连、导航返回及 TTL 到期均不会自动读取。输入不能是 `sources`、域名、网址、端口、CIDR 或带 zone 的 IPv6；IPv4-mapped IPv6 归一为 IPv4。前端只校验字面量，公网范围仍由后端权威校验并返回 400。

一次只允许一组读取，重复提交不重复发送。整个读取（含响应体和来源目录）最多 20 秒；取消、输入修改和卸载会中止请求。请求身份隔离可丢弃乱序与不遵守取消的晚到响应，A→B→A 不恢复旧结果。错误与 429 不自动重试，不绕过服务端限制。

## 结果语义

| 情况 | 页面含义 |
| --- | --- |
| 404 | 暂无有效缓存：可能未检测、已过期或配置已变更；后端不能区分这些原因，不能断言“从未检测” |
| 200 + 成功来源 | 有缓存观测，不代表安全、节点健康或账户可用 |
| 200 + 部分/全部来源失败 | 保留逐来源状态、错误、时间及原始 JSON；部分失败、全部失败、unavailable 分别表达 |
| 读取后来源到期 | 隐藏派生摘要和该过期来源数据，标记过期；计时器不产生请求 |
| 401/403/503 | 清除旧事实，明确权限或插件不可用；目录接口返回这些状态也会抑制缓存结果 |
| 其他目录错误 | 与缓存观测独立展示目录读取失败，不声称目录可用 |
| IP 不匹配、via-node、格式异常 | 隐藏结果并提示响应不匹配或格式无效 |

数值 0、布尔 false、null 和 unknown 保持各自含义；空滥用标记不代表无风险。by-IP 页不展示节点出口一致性、Cloudflare 或 AI 经节点可用性结论。当前实际 by-IP 适配器为离线 db-ip，目录中的 available 不保证离线库已加载；页面也不额外下载数据库。

## 设计与验证

沿用资源页的 Card/Input/Button/Badge、蓝白主题、Manrope 正文和 Sora 标题；表单左对齐，状态使用文字表达，来源明细按需展开。输入有可访问名称、关联帮助和错误；提交错误回到输入，取消恢复输入焦点。中英文同步，手机和横屏可用，无新增依赖。

`npm test` 覆盖字面量/规范化、响应归属、错误语义和时效；`npm run test:browser:byip` 使用隔离 Chrome 与内存 fixture，覆盖只读流量、键盘输入/取消、导航、旧响应、20 秒传输/响应体超时、各种错误、过期、来源明细及移动布局。API fetch 无真实网络回退。CI 在 Ubuntu/Windows 执行这些检查和既有 Go test/race/build/vet；成功只说明工程验收，不是实网验收或部署。
