# 显式单次 IP 质量检测

资源页的「手动 IP 质量检测」支持输入公网 IP 或单个节点 Hash；节点详情缓存面板也提供预填节点的入口。页面复用 P1 单次 API，不自动启用插件、选择来源、探测出口或修改配置。首次进入、编辑、返回、聚焦、网络恢复和观测过期均不会发起检测。

## 操作与请求

1. 输入对象后，显式点击「加载对象与来源」。IP 模式只读来源目录；节点模式先读取节点，再读取来源目录。IPv4、IPv6 和 IPv4-mapped IPv6 规范化后使用；节点 Hash 必须是 32 位十六进制。地址是否属于允许范围由后端最终校验。
2. 逐项选择当前启用、可用且受支持的无密钥来源，默认不选中任何来源。按 IP 模式只允许 by-IP 来源；当前可执行的是本地 DB-IP。节点模式还允许配置好的出口一致性、Cloudflare challenge 和 AI region 来源。目录可用不代表数据库就绪或观测成功。
3. 点击「执行一次检测」，发送带明确非空 `sources` 和 `force` 的一次 POST。节点使用 `POST /api/v1/nodes/{hash}/actions/check-ip`，IP 使用 `POST /api/v1/ip-checks/lookup`。没有自动重试、批量任务或后台调度。
4. 可单独点击「读取当前缓存核对」，只发送 GET，不发起检测。缓存可能为空、过期或只保留部分已完成来源；404 不能解释为从未检测。

节点 POST 前后都重新读取当前节点，核对 Hash、出口 IP 和出口版本。发送前复核发现变化时阻止发送；响应后复核发现变化时隐藏结果。读取快照与 POST 之间仍可能发生变化，页面不冻结出口，也不承诺此时服务端绝未执行；后端继续执行自己的出口和版本校验。输入、对象类型或路由变化会清空当前准备状态和结果，防止 A→B→A 或晚到响应恢复旧证据。

通过节点的来源会访问管理员配置的外部目标，目标可看到节点出口 IP。具体 URL 在插件配置中维护，此页不读取或修改目标列表，也不使用需密钥的来源。按 IP 结果不展示出口一致性、Cloudflare、ChatGPT 或 Claude 等经节点结论。

## 缓存、停止与错误语义

`force:false` 默认允许复用有效缓存，不保证生成新的外部请求；以来源观测时间为准。`force:true` 跳过有效缓存，但仍可能加入相同对象和来源的在途工作。来源选择和 force 在请求期间锁定，重复点击不会增加请求。

对象/目录准备和显式缓存读取的客户端等待上限为 20 秒；执行检测的整个客户端等待上限为 130 秒，覆盖节点前后核对、响应头和响应体。130 秒不是服务端总超时承诺：后端每个来源的排队与执行受配置超时限制，缓存保存另有预算。超时后需要用户手动决定是否核对缓存或再次检测。

「停止等待」、编辑和离开页面会取消当前客户端请求。停止、超时、网络失败或最终 HTTP 错误，都不能证明服务端未执行。已完成来源的缓存写入不回滚；其他调用者共享的检测可能继续。成功响应也不保证缓存持久化成功。界面只标记已有节点缓存查询过期，不主动重新读取。

本切片修复后端两处取消准入边界：等待引擎锁后再次检查调用者取消；取得执行槽并读取缓存后再次检查工作上下文取消，避免已取消的独立调用继续启动来源。保留共享等待者和已完成缓存的原有语义；不新增速率或配额策略。

| 情况 | 展示与动作 |
| --- | --- |
| 200，全部来源成功 | 已返回观测；不等于节点健康、账户可用或无风险 |
| 200，部分来源失败 | 保留有效观测、逐来源错误和原始数据；失败不可覆盖为通过 |
| 200，全部失败或 unavailable | 隐藏聚合摘要，保留逐来源错误及原始部分证据 |
| 观测到期 | 隐藏摘要和过期来源数据，不自动刷新或检测 |
| 响应 IP、来源集合、类型或字段无效 | 隐藏结果；提示缓存可能已变化 |
| 400/404/409 | 提示重新准备对象或检查选择；不自动探测节点出口 |
| 401/403/503 | 保留权限、插件不可用、繁忙或超时的边界；不自动启用插件 |
| 429 | 提示稍后手动重试；不重试或绕过服务端限制 |

未知、数值 0 和布尔 false 保留各自含义；无滥用标记不等于无风险。现有 POST 有引擎并发上限、等待队列和相同检查合并，但没有每来源 QPS/日配额。批量缓存读取 API 的限流不能冒充检测来源配额。

## 验证范围

单元测试检查输入、来源选择、节点身份、响应字段、错误与结果状态。`npm run test:browser:manual` 使用独立 Chrome、随机回环端口和内存响应，检查显式动作、准确请求、重复提交、取消、节点变化、晚到响应、部分/全部失败、缓存核对、键盘与移动布局。20/130 秒等待截止通过显式触发记录的客户端定时器验证；不声称等待了真实的 130 秒。到期隐藏使用实际短 TTL。

后端取消回归使用合成 host/store/source，旧实现存在确定性失败；修复后运行相关 race 检查。最终版本、独立复审、双平台 Go test/race/build/vet 和 WebUI CI 以 PR 验收记录为准。没有真实节点、外部目标、密钥、部署或发行操作。批量检测、后台调度、来源配额/熔断和风险评分仍属于后续切片。
